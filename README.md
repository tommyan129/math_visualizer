# math_visualizer

대학 수학 공부용 수식 시각화 도구. Claude가 MCP로 DSL 요청을 보내면 Rust 서버가 해석·검증해서 상태 모델로 확정하고, 브라우저가 계산·샘플링·렌더링합니다.

수식 입력법을 따로 익히지 않아도 Claude가 대신 그려주고, 강조·scene·step·note로 시각 자료를 조작해 이해를 돕는 것이 목표입니다.

## 빠른 시작

필요: Rust (rustup), Node.js, Claude Code

```sh
# 1. 프론트엔드 빌드
cd web && npm install && npm run build && cd ..

# 2. 서버 실행
cargo run -p server

# 3. Claude Code에 MCP 서버 등록 (한 번만)
claude mcp add --transport http math-visualizer http://127.0.0.1:7800/mcp
```

4. 브라우저에서 `http://127.0.0.1:7801/` 을 엽니다.
5. 왼쪽 사이드바의 **새 작업 공간**을 눌러 이름을 적고 Enter.
6. 작업 공간 항목의 `⋯` 메뉴 → **key 생성**. 나온 key를 복사합니다 (다시 볼 수 없음).
7. Claude Code에서 key와 함께 부탁합니다.

   > 작업 공간 key는 `calculus-3f9a…` 야. f(x) = x³ − 3x 그려주고 극값 표시해줘.

Claude가 `apply`를 보내면 브라우저에 바로 그려집니다.

## 사용법

### 작업 공간과 key

작업 공간은 정의·강조·scene·요청 기록을 담는 단위입니다 (대화 세션 목록처럼 사이드바에서 만들고 고름).

- **만들기**: 사이드바 **새 작업 공간** → 이름 입력 → Enter (Esc 취소).
- **key**: 작업 공간마다 `⋯` 메뉴에서 **key 생성**. key는 `이름-무작위32자리` 모양이고, Claude가 그 작업 공간에 접근하는 유일한 수단입니다.
  - key는 만들 때 한 번만 보입니다. 서버는 해시만 저장하므로 잃어버리면 **key 교체**로 새로 만듭니다. 교체하면 이전 key는 즉시 무효가 됩니다.
  - key가 없는 작업 공간에는 "key 없음"이 표시됩니다.
  - 잘못된 key가 1분 안에 10번 넘게 들어오면 1분 동안 모든 key 확인이 거절됩니다.
- **고르기**: 사이드바에서 항목을 누릅니다. Claude가 다른 작업 공간에 scene을 만들면 화면이 그리로 넘어가고, 사이드바 활성 항목과 상단 바 이름이 바뀝니다.
- 사이드바는 접을 수 있습니다 (접으면 펼치기·새 작업 공간 아이콘만 남음).

### Claude에게 요청하기

자연어로 부탁하면 Claude가 DSL로 바꿔서 `apply`로 보냅니다. key는 대화마다 한 번 알려주면 됩니다.

부탁 예:

- "sin(ax)를 a 슬라이더로 그려줘. a 범위는 0.5에서 5."
- "x² 아래 0에서 2까지 넓이를 칠하고, 리만 합 사각형을 n개로 보여줘."
- "(x+1)² − (x−1)² = 4x 전개 과정을 단계별로 보여줘."
- "z = x² − y² 곡면을 3D로, 원점 근처만 강조해줘."
- "접선이 움직이는 모습을 step으로 나눠서 설명해줘."

Claude가 할 수 있는 일:

- 그리기·수정·삭제 (같은 이름으로 다시 정의하면 수정, 참조하는 것도 함께 정리)
- 구간별 함수, 매개변수·극좌표 곡선, 음함수, 반복(`family`), 3D 곡면·공간 곡선
- 도함수·역함수, 극값·근·교점·변곡점·불연속점 찾기
- 계산 과정(`calc`): 단계별 식, 바뀐 부분 색칠, 브라우저 수치 검증 결과 확인
- 강조(넓이, 영역, 식의 일부 색칠), 슬라이더 상수 조건
- scene(보기 프리셋)과 step(순서대로 보여주기), note(설명 문구), animate
- 화면 상태 확인(`get_state`), 캡처(`snapshot`), 사용자 요청사항 확인(`get_requests`)

한 요청은 전부 적용되거나 전부 거절됩니다. 오류가 있으면 Claude가 `줄:열 [오류 코드] 설명 → 후보` 형식의 응답을 보고 고쳐서 다시 보냅니다.

### 화면 구성

```
┌──────────┬─────────────────────────────────────────────────┐
│          │ 작업 공간 이름 │ scene 탭 │        연결 상태 · rev │
│ 작업 공간 ├────────────┬────────────────────────────────────┤
│ 사이드바  │ 정의       │                                    │
│          │ 강조       │             캔버스                 │
│ 새 작업   │ 상수       │                                    │
│ 공간      │ clip       ├────────────────────────────────────┤
│          │            │ ◀ step n / m ▶   note              │
│ 휴지통    │            ├────────────────────────────────────┤
│ 설정      │            │ 서랍: DSL 입력 / 요청사항          │
└──────────┴────────────┴────────────────────────────────────┘
```

**상단 바**

- scene 탭: 기본 scene은 좌표계 이름(`2D(x, y)`, `polar(r, θ)`, `3D(x, y, z)`), Claude가 만든 scene은 번호. 다른 scene이 갱신되면 탭에 노란 점.
- 오른쪽: 연결 상태와 revision. 같은 작업 공간을 다른 탭에서 열면 "다른 탭에서 열림"이 뜨고 **여기서 열기**로 되가져올 수 있습니다.

**정의·토글 패널**

- **정의**: 체크박스로 켜고 끄기. 식 안의 함수 이름이 그래프 색과 같습니다. 그리지 않는 값(벡터·행렬)에는 체크박스가 없습니다.
  - 특징점(극값 등)은 찾은 좌표가 함께 나오고, **좌표** 버튼으로 캔버스의 좌표 라벨을 켜고 끕니다.
  - 계산 과정·도함수·역함수의 수치 검증 결과: ✓ 일치 / ✗ 불일치 / △ 조건부 일치 / ? 검증 불가 / – 검증 안 됨.
  - 경고(처음 화면에 보이는 점 없음 등)는 정의 아래 노란 줄로 붙습니다.
- **강조**: 체크박스 + 색 칩 + 대상·범위, 아래에 memo. 기본 scene에서는 꺼진 채 시작합니다.
- **상수**: 상수 하나가 카드 하나.
  - 슬라이더를 끌거나 값 칸에 숫자를 입력. **Shift를 누른 채 끌면 한 칸(step)씩** 움직입니다.
  - 아래 양 끝의 최솟값·최댓값 칸을 고쳐 범위를 바꿀 수 있습니다.
- **clip**: 이 범위 밖은 그리지 않습니다. 부등식으로 직접 고칠 수 있고, 되돌리기 버튼으로 Claude가 정한 clip으로 돌아갑니다.

**캔버스 (2D)**

- 휠: 확대·축소 / 왼쪽 끌기: 화면 이동
- 오른쪽 위 버튼: 확대, 축소, 처음 view로
- 왼쪽 아래: 커서 좌표

**캔버스 (3D, 자유 카메라)**

| 조작 | 기본 키 |
|---|---|
| 화면과 평행 이동 | 왼쪽 버튼 끌기 |
| 시선 돌리기 | 오른쪽 버튼 끌기 |
| 앞 / 뒤 / 왼쪽 / 오른쪽 | W / S / A / D |
| 위 / 아래 | Space / Q |
| 이동 속도 ×1 → ×2 → ×5 | Shift (누를 때마다) |
| 가리킨 곳으로 다가가기·물러나기 | 휠 |

- 키 조작은 마우스가 3D 화면 위에 있을 때만 동작합니다.
- 확대·축소 버튼 아래에 바닥 격자, 세 번째 축 격자 켜기/끄기 버튼과 이동 속도 버튼이 있습니다.

**step·note 바**

- ◀ / ▶ 또는 ← / → (PageUp / PageDown)로 이전·다음 step.
- 앞으로 갈 때는 그 step이 정한 것만 바뀌고 사용자가 바꾼 나머지는 유지됩니다. 뒤로 가면 지나온 step이 바꾼 것만 되돌립니다.
- step에 animate가 있으면 들어올 때 재생됩니다. 슬라이더를 잡으면 멈춥니다.
- note의 수식은 TeX 글꼴로 보입니다.

### 요청사항 (Claude에게 피드백 남기기)

그림을 보다가 이상한 곳이 있으면 서랍의 **DSL 입력**에 `req`를 적고 **적용**을 누릅니다.

```
req(f; 0.9 < x < 1.1; "x = 1 근처에서 선이 끊겨 보임")
req(g.den;; "분모 부호가 반대 같음")
req(H1)
req(scene(1).step(3);; "이 단계 설명이 이해가 안 됨")
```

- 형식: `req(대상; 범위; memo)`. 대상만 필수이고 빈칸은 비워 둡니다.
- 대상: 함수, 강조, 식의 일부(`f.(b*x).coef`, `g.den` 등), `scene(n)`, `scene(n).step(m)`.
- Claude에게 "요청사항 확인해줘"라고 하면 `get_requests`로 읽고 고칩니다. 응답에는 요청 이후 대상이 그대로인지 / 수정됐는지 / 삭제됐는지도 나옵니다.
- **요청사항** 탭에서 목록과 변경 상태를 보고, 처리된 것은 체크합니다 (Claude도 처리 후 표시함).

DSL 입력칸은 `req`뿐 아니라 모든 DSL을 받습니다 (Claude의 요청과 같은 경로로 서버에 감). 직접 `define:` 블록을 적어 그릴 수도 있습니다.

### 설정과 휴지통

- **설정** (사이드바 아래 톱니): 단축키 변경. 칸을 누른 뒤 키나 마우스 버튼을 누르면 바뀝니다 (Backspace 지우기, Esc 취소). 동작마다 두 칸. 설정은 브라우저별로 저장됩니다.
- **휴지통으로 이동**: 작업 공간 `⋯` 메뉴. 휴지통의 작업 공간은 key가 막혀서 Claude가 쓸 수 없습니다.
- **휴지통** (사이드바 아래): **복원**하면 같은 key로 다시 쓸 수 있고, **영구 삭제**는 되돌릴 수 없습니다.

## DSL 요약

평소에는 Claude가 DSL을 대신 쓰므로 외울 필요는 없습니다. 직접 쓰거나 Claude의 요청을 읽을 때 참고하세요. 전체 문법은 MCP `describe` 도구로 볼 수 있습니다 (Claude에게 "describe(3D) 보여줘"처럼).

### 정의

```
define:
    f(x; a, b) -> y: a*x^2 + b*x + 1        # ';' 앞은 입력, 뒤는 상수(슬라이더), '->' 뒤는 출력 축
    g(x; a, b) -> y: f(x) + 1               # 부르는 함수가 쓰는 상수도 적음
```

- 블록 안은 스페이스 4칸 들여쓰기, 한 줄에 정의 하나. 같은 이름으로 다시 쓰면 수정.
- 축 이름이 좌표계: `g(t) -> y`는 `2D(t, y)`에 그려짐.
- 곱셈 `*` 필수(`2*x`), 그리스 문자는 `\alpha`, `\theta`, 아래첨자는 `x_{1}`, `\pi`, `\e`.
- `-x^2 = -(x^2)`, 지수는 `x^(n+1)`, 함수 거듭제곱은 `sin(x)^2`, 로그는 `ln`, `log10`, `log2`, `log(x, b)`.
- 삭제: `del f`, `del f, g`, `del scene(1)` (참조하는 정의도 연쇄 삭제).

### 그리는 것들

```
define:
    # 구간별 함수
    s(x; a, b) -> y:
        split x at a, b
        -1,     x < a
        x^2,    a <= x <= b
        3 - x,  x > b

    # 매개변수 곡선 (범위 필수), 극좌표, 음함수
    p(t) -> (x, y): (cos(t), sin(t)), 0 <= t <= 2*\pi
    h(\theta) -> polar(r): 1 + cos(\theta)
    C(x, y; a): x^2 + y^2 = a^2

    # 반복: 정수 k마다 하나씩
    O(x, y; m): family(x^2 + y^2 = k^2; 1 <= k <= m)

    # 3D: 곡면, 공간 곡선, 매개변수 곡면
    g(x, y) -> z: x^2 - y^2
    q(t; a) -> (x, y, z): (cos(t), sin(t), a*t), 0 <= t <= 4*\pi
    sp(u, v) -> (x, y, z): (cos(u)*sin(v), sin(u)*sin(v), cos(v)), 0 <= u <= 2*\pi, 0 <= v <= \pi

    # 벡터·행렬, span, 화살표
    A: [[1, 2], [3, 4]]
    v(; a): [1, a]
    S(; a): span(v, [0, 1])
    w(; c): arrow([1, 2*c]; [c, c^2])        # 시작점은 ';' 뒤
```

행렬 연산: `A + B`, `2*A`, `matmul(A, B)`, `pow(A, n)`, `inv(A)`, `transpose(A)`, `det(A)`, `tr(A)`. 원소는 `A_[1, 2]`, `v_[2]`.

### 도함수·특징점·계산 과정

```
define:
    f(x) -> y: x^3 - 3*x
    f@1(x) -> y: 3*x^2 - 3                  # 화면엔 f'. 정의하지 않은 f@n은 서버가 기호 미분
    E: extrema(f)                           # 극대·극소
    R: roots(f; -1 < x < 2)                 # 근 (범위 칸)
    I: inflections(f)
    P: intersect(f, g)
    B: breaks(f;; hole)                     # 구멍·점근선·점프·끝점·뾰족점
    M: argmax(f; -2 <= x <= 3)
    T(x) -> y: f@1(E_[1])*(x - E_[1]) + E_[2]   # 점이 하나면 값으로 씀

    u(x) -> y: (x+1)^2 - (x-1)^2
    v(x) -> y: (x^2 + 2*x + 1) - (x^2 - 2*x + 1)
    w(x) -> y: 4*x
    K: calc(u, v, w)                        # 단계별 식 + 바뀐 부분 색칠 + 수치 검증
```

역함수는 `~f(x) -> y: ...`로 정의 (화면엔 f⁻¹). `calc(p, P;; integral)`은 적분 관계를 검증합니다.

### 강조·상수·style

```
H1 = highlight(f; 0 <= x <= 2; blue; "정적분 넓이")    # f와 x축 사이
H2 = highlight(; between(f, g) and 0 <= x <= 2; green) # 영역 칠하기
H3 = highlight(f.(b*x).coef;; orange)                   # 식 속의 b만 색칠

constant:
    a: range=(-5, 5), default=1, step=0.1
    n: integer, range=(1, 50), default=4

style up:
    color: orange
    fill: above
    opacity: 0.25
```

기본 style: `blue orange green red purple yellow gray`.

### scene·step·note

```
scene(1):
    space: 2D(x, y)
    show: f, H1                             # 처음 켜질 것 (나머지는 꺼짐)
    hide: H2                                # 공개 전까지 목록에서도 숨김
    view: -5 <= x <= 5 and -3 <= y <= 3     # 처음 카메라
    clip: -10 <= x <= 10
    step:
        show: +T, -H1
        set: a = 2
        note: "{f}의 극대점에서 접선 {T(x)}"
    step:
        animate: n = 4 -> 64, 2s, loop
        note: + "$n$이 커질수록 넓이에 가까워짐"
```

- 새 scene을 만들면 브라우저가 그리로 이동합니다. step은 이전 step과 달라진 것만 적습니다.
- note의 `{식}`은 DSL로 해석되고, `$...$`는 LaTeX 그대로 들어갑니다.
- animate 끝의 `loop`는 왕복, `repeat`는 처음부터 되풀이.

## MCP 도구

| 도구 | key | 하는 일 |
|---|---|---|
| `apply` | 필요 | DSL 요청 적용 (전부 또는 전무). 바뀐 것, 서버가 자동으로 한 일, 수치 검증 결과, 또는 모든 오류를 반환 |
| `get_state` | 필요 | 현재 화면 상태: scene, 정의, 슬라이더 값, view, 특징점 좌표, 경고 |
| `get_requests` | 필요 | 사용자 요청사항(req)과 대상의 변경 상태. `done=[번호]`로 처리 표시 |
| `snapshot` | 필요 | 브라우저 캔버스 PNG (라벨 포함). 색 구분·겹침 같은 시각적 확인용 |
| `describe` | 불필요 | DSL 도움말. 이름 없이 부르면 명령 목록 |

`apply`·`snapshot`·수치 검증은 브라우저 결과를 받아야 하므로 해당 작업 공간이 브라우저에 열려 있어야 정확한 응답이 옵니다.

## 구조

```
Claude ──MCP(HTTP)──▶ server (Rust) ──WebSocket──▶ browser (TypeScript)
                      해석·검증·이력              계산·샘플링·렌더링
```

- **서버는 수식 값을 계산하지 않습니다.** 파싱, 이름 해석, 타입 검사, 구조 기반 비용 판단, 기호 미분(AST 변환)만 하고 확정된 AST를 브라우저로 보냅니다.
- **호스트 eval 없음.** 식은 자체 parser를 거치고, 브라우저 codegen은 검증된 AST 노드 종류로만 JS를 조립합니다. 내장 함수는 화이트리스트이며 인터프리터는 fuel·시간·깊이·할당 상한을 가집니다.
- **요청 기록은 추가만 됩니다.** 모든 `apply`는 원자적으로 적용되고 SQLite에 남습니다.

| 경로 | 내용 |
|---|---|
| `crates/dsl` | lexer, parser, AST, 이름 해석, 타입 검사(벡터·행렬), 인터프리터, 기호 미분 |
| `crates/model` | 확정된 상태 모델, WebSocket 메시지 (ts-rs로 TS 타입 생성) |
| `crates/server` | axum HTTP/WebSocket, rmcp MCP 엔드포인트, SQLite 요청 로그, 작업 공간 key·휴지통 |
| `web` | TypeScript + Vite (UI 프레임워크 없음), Web Worker 계산, Canvas 2D / three.js 렌더러, MathJax |

## 실행 옵션

리스너가 둘입니다. MCP용(공개)과 브라우저용(사설)을 나눠서, 브라우저 쪽은 VPN 등 신뢰하는 네트워크에만 열 수 있습니다. 기본값은 둘 다 localhost입니다.

| 환경 변수 | 기본값 | 내용 |
|---|---|---|
| `MV_PUBLIC_ADDR` | `127.0.0.1:7800` | MCP 엔드포인트 (`/mcp`) |
| `MV_PRIVATE_ADDR` | `127.0.0.1:7801` | 브라우저 페이지와 WebSocket |
| `MV_DB` | `data/mv.db` | SQLite DB (작업 공간, 요청 기록) |
| `MV_WEB_DIST` | `web/dist` | 빌드된 프론트엔드 |

프론트엔드 개발 서버: `cd web && npm run dev` (`/ws`를 `MV_PRIVATE_ADDR`, 기본 `127.0.0.1:7801`로 프록시). 서버는 따로 `cargo run -p server`로 띄워 둡니다.
